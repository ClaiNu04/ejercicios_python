# 🐍 100 Ejercicios de Python

Una colección de **100 ejercicios prácticos para aprender y reforzar Python**, desde los conceptos más básicos hasta problemas que requieren aplicar varios conceptos al mismo tiempo.

El objetivo no es simplemente completar los ejercicios, sino **aprender a resolver problemas utilizando Python** y desarrollar una base sólida de programación.

## 🎯 Objetivos

Con estos ejercicios podrás practicar:

* Variables y tipos de datos
* Operadores
* Condicionales (`if`, `elif`, `else`)
* Bucles (`for`, `while`)
* Listas, tuplas, conjuntos y diccionarios
* Strings
* Funciones
* `return`
* `*args` y `**kwargs`
* List comprehensions
* `enumerate()`, `zip()` y `range()`
* Manejo de excepciones
* Archivos
* Módulos
* Programación orientada a objetos
* Clases y objetos
* Métodos especiales como `__init__`
* Algoritmos y resolución de problemas

Cada ejercicio contiene una descripción del problema y un espacio para desarrollar la solución.

## 🚀 Cómo utilizar este repositorio

La recomendación es intentar resolver cada ejercicio **antes de buscar una solución**.

Un buen proceso de aprendizaje es:

```text
1. Lee el problema
       ↓
2. Intenta resolverlo
       ↓
3. Identifica qué concepto no entiendes
       ↓
4. Investiga ese concepto
       ↓
5. Intenta nuevamente
       ↓
6. Comprueba tu solución
```

No es necesario resolver los 100 ejercicios de una sola vez. Lo importante es comprender qué estás haciendo.

## 💡 Recomendación

Si un ejercicio parece demasiado difícil, divídelo en problemas más pequeños.

Por ejemplo, en lugar de intentar resolver un proyecto completo de una vez:

```text
Proyecto
├── Crear los datos
├── Mostrar los datos
├── Obtener información
├── Modificar información
└── Validar resultados
```

Resuelve cada parte individualmente y después júntalas.

## 🛠️ Requisitos

* Python 3.x
* Un editor de código, como VS Code, PyCharm u otro de tu preferencia.

Puedes comprobar tu versión de Python con:

```bash
python --version
```

## 🎓 Filosofía del proyecto

Este repositorio está pensado para **aprender haciendo**.

No necesitas conocer todo Python antes de comenzar. Es normal encontrarse con conceptos desconocidos durante los ejercicios.

La meta es pasar progresivamente de:

> "No sé cómo hacerlo"

a:

> "Sé qué conceptos necesito y puedo encontrar la forma de hacerlo."

## ⭐ ¿Por qué 100 ejercicios?

Resolver muchos problemas pequeños ayuda a desarrollar algo más importante que memorizar sintaxis: **la capacidad de pensar como programador**.

Cada ejercicio es una oportunidad para practicar, equivocarse, investigar y volver a intentarlo.
